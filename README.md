# CppServiceKit

cpp, cpp17, scaffold, backend, microservices, middleware, toolkit, server-development

CppServiceKit 是一个面向 C++ 服务端开发的模块化脚手架项目，旨在整合常用第三方库与中间件 SDK，构建可复用、易扩展的基础开发组件，减少重复开发工作，提高工程开发效率。

项目围绕配置管理、日志系统、网络通信、数据序列化、单元测试、音视频处理及数据存储等典型场景展开，计划集成 gflags、spdlog、Google Test、JsonCpp、Protobuf、cpp-httplib、brpc 等基础工具，并逐步扩展 Redis、MySQL、RabbitMQ、etcd、Elasticsearch 等中间件支持。

通过模块化封装与统一的工程组织方式，为不同类型的 C++ 服务端项目提供可复用的基础能力。
